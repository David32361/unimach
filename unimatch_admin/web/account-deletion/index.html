Qué implica la eliminación

El procedimiento preparado elimina el acceso, perfil, dispositivos, sesiones, intereses, matches, bloqueos y reportes asociados. Las conversaciones y sus mensajes compartidos también se borran para la otra persona. Los datos borrados definitivamente no pueden recuperarse.

Quejas, sugerencias y apelaciones

Usa el mismo correo para solicitar revisión de una suspensión, baneo o eliminación administrativa. Indica la fecha y el motivo que muestra UniMatch. Una apelación no garantiza la reactivación ni recupera datos que ya se borraron.
